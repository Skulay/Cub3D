## Description

cub3D is a 3D maze renderer built in C using the raycasting technique, inspired by Wolfenstein 3D. The goal is to parse a `.cub` scene file describing a map, textures, and colors, then render a first-person view of the environment in real time using MiniLibX.

The renderer uses a Digital Differential Analyzer (DDA) algorithm to cast one ray per screen column, determine the distance to the nearest wall, and draw a textured vertical slice accordingly. Floor and ceiling are filled with flat colors, and the camera can be moved and rotated freely.

## Instructions

**Dependencies (Linux)**

Make sure the following are installed before building:

```
gcc, make, libx11-dev, libxext-dev, zlib1g-dev
```

On Ubuntu/Debian:
```
sudo apt install gcc make libx11-dev libxext-dev zlib1g-dev
```

**Compilation**

```
make
```

MinilibX is cloned automatically from the 42Paris repository if not already present.

**Running**

```
./cub3D path/to/map.cub
```

A `.cub` file must follow this format:

```
NO ./path/to/north_texture.xpm
SO ./path/to/south_texture.xpm
WE ./path/to/west_texture.xpm
EA ./path/to/east_texture.xpm
F 220,100,0
C 0,0,0

111111
100001
100N01
111111
```

Valid map characters are `1` (wall), `0` (empty space), and one of `N S E W` for the player start position and orientation. The map must be fully enclosed by walls.

**Controls**

| Key | Action |
|---|---|
| W / S | Move forward / backward |
| A / D | Strafe left / right |
| ← / → | Rotate camera |
| ESC | Quit |

**Cleanup**

```
make clean    # remove object files
make fclean   # remove object files and binary
make re       # full rebuild
```
